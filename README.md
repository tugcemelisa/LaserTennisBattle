Laser Tennis Battle
A local two-player arena battler where sweeping laser hazards turn a tennis-style court into an ever-changing minefield. Laser Tennis Battle is a local multiplayer arena game built in Unity. Players compete across a split arena, dodging dynamic laser hazards that evolve each round while racing to claim victory. Designed for both keyboard and gamepad, it features custom menus, settings, and intuitive controls.
